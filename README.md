# АСОШ №2 — Умный дневник

Электронный помощник для учеников МОУ АСОШ №2 (с. Аргаяш): расписание уроков и звонков, таймер до конца урока, домашние задания, чат класса, помодоро-таймер, мини-игры и другое.

Стек: React 19, Vite, Tailwind CSS, Firebase Realtime Database (чат и общие данные класса). Сервер не нужен: приложение целиком работает в браузере и публикуется на GitHub Pages.

Приложение: https://kafeevbogdan347-ui.github.io/asosh-timer/

## Запуск на компьютере

Нужен Node.js 20 или новее.

```bash
npm install
cp .env.example .env   # заполните значения в .env
npm run dev            # http://localhost:3000
```

## Настройки (.env)

| Переменная | Зачем |
|---|---|
| `CLASS_CODES` | коды классов: `5А:код,5Б:код,...` |
| `DEV_PASSWORD` | пароль панели разработчика |
| `VITE_FIREBASE_*` | настройки Firebase для чата класса |

Коды классов и пароль разработчика при сборке превращаются в медленные отпечатки (PBKDF2, 100 000 повторов): открытым текстом их нет ни в репозитории, ни в собранном приложении, и подбирать их перебором очень долго. Короткие коды всё равно делайте длинными и случайными (например, `7А-K4P9XM`).

## База Firebase

Чат, общие замены и ДЗ, объявления учителей и перенос по QR хранятся в Firebase Realtime Database. Приложение входит в Firebase анонимно (без логина и пароля). Что кому можно, решают правила базы `database.rules.json`, а не само приложение:

- **Чат класса** читают и пишут только ученики, которые ввели код класса, и учителя. Код проверяет база: устройство записывает себя в `asosh_members/<класс>` с ключом участника, и база сверяет этот ключ с `asosh_class_keys`.
- **Замены и ДЗ класса** видят все, кто выбрал класс (в том числе гости). Добавлять их могут только ученики класса и учителя, удалять только автор.
- **Общий чат школы** открыт всем вошедшим.
- Все сообщения проверяются на сервере: длина, время сервера, только известные поля, грубый мат (основной фильтр работает в приложении, `src/utils/moderation.ts`).
- **Статистику устройств** читают только администраторы из `asosh_admins`.
- **Перенос по QR**: одна запись на устройство, через 30 минут база её уже не отдаёт.
- **Профили учеников и оценки.** Ученик класса отправляет из профиля имя в виде «Иван П.»: полной фамилии на сервере нет. Приложение отсекает явно выдуманные имена, база проверяет формат. Учитель в кабинете подтверждает учеников, которых узнаёт, и ставит им оценки от 2 до 5. Оценки видят только сам ученик и учителя. При переносе на новый телефон по QR профиль и оценки переезжают вместе с остальными данными.

### Первая настройка (один раз)

1. **Authentication → Sign-in method → Anonymous → Enable.**
2. **Ключи классов.** На компьютере, где есть `.env` с `CLASS_CODES`, выполните `npm run class-keys`, и появится файл `class-keys.json`. В консоли Firebase: **Realtime Database → Data**, создайте узел `asosh_class_keys`, откройте его, нажмите **⋮ → Import JSON** и выберите `class-keys.json`. Импортируйте именно в узел `asosh_class_keys`, а не в корень базы, иначе импорт сотрёт остальные данные. Файл не коммитится, после загрузки его можно удалить.
3. **Правила.** **Realtime Database → Rules**: вставьте содержимое `database.rules.json` и нажмите **Publish**. Или из консоли: `npx firebase deploy --only database --project <id проекта>`.
4. **Администратор статистики** (по желанию). Откройте в приложении панель разработчика → «Статистика» и скопируйте uid устройства. В **Realtime Database → Data** добавьте `asosh_admins/<uid>` со значением `true`.

Порядок важен: сначала опубликуйте новую версию приложения, потом загрузите ключи и только после этого правила. Старые версии приложения (в том числе старые APK) после смены правил не смогут писать в чаты, их нужно обновить. Ученикам, которые вошли в класс до этого обновления, приложение один раз предложит ввести код класса заново.

### Проверка правил

```bash
npm run test:rules
```

Тесты (`tests/rules.test.mjs`) запускают правила в эмуляторе Firebase. Нужна Java 11 или новее.

Чтобы погонять всё приложение без настоящей базы, добавьте в `.env` строку `VITE_FIREBASE_EMULATOR=1` и запустите эмуляторы командой `npx firebase emulators:start --only auth,database --project demo-asosh`.

## Публикация

Сборка и публикация на GitHub Pages идут автоматически при каждом коммите в `main` (`.github/workflows/deploy.yml`).

Настройки берутся из секрета репозитория `APP_ENV`: **Settings → Secrets and variables → Actions → APP_ENV**. В него кладётся всё содержимое `.env`.

### Новые коды классов на учебный год

1. Откройте секрет `APP_ENV` и замените строку `CLASS_CODES=...` новыми кодами.
2. Запустите сборку заново: **Actions → Deploy to GitHub Pages → Run workflow**.
3. Обновите ключи в базе: впишите новые коды в свой `.env`, выполните `npm run class-keys` и импортируйте `class-keys.json` в узел `asosh_class_keys` (см. «Первая настройка», шаг 2).

Старые коды перестанут работать сразу после публикации. Ученики, которые уже вошли в свой класс, останутся в нём и сохранят доступ к чату класса.
